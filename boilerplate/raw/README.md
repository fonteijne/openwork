# Raw sources

Put selected source material here for compilation. Keep source originals intact; use descriptive filenames and retain provenance in the filename or source document where practical (author/publisher, date, URL, and access date).

For email, Slack, or chat text pasted into a session, the default shared record is an approved, concise communication note—not a verbatim copy of the conversation. Draft the note with the contributor, minimize details to what colleagues need, and get their approval before saving it here. Identify it as a selective summary, retain available source/date/link provenance, and disclose if it is based on partial pasted text or cannot be checked against a thread colleagues can access. Do not save the original conversation unless the contributor separately and explicitly asks for it and sharing is appropriate.

Nothing in this folder is considered compiled knowledge until it has been reviewed and integrated into `../wiki/`. Do not overwrite an original with an edited summary. Communication notes are derived source records, not originals; keep them distinct from any preserved original. Other summaries and syntheses belong in the wiki or output, with a link back to the source.
