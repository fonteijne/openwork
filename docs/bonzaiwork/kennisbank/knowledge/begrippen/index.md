# Glossary Term

* [Brein](brein.md) - Een project waarvan de map een git-repo is die BonzaiWork synchroniseert: een gedeeld projectbrein, of het persoonlijke brein (in de UI Mijn agent).
* [Chat](chat.md) - Een gesprek met de agent; in de engine een session die via zijn home bij precies één workspace hoort. Chats kunnen in groepen staan.
* [Key](key.md) - Een LiteLLM virtual key, per gebruiker of per project; staat in de OS-keychain en is in de UI alleen als hint zichtbaar.
* [Project](project.md) - Eén map op schijf met zijn chats, skills, connecties en bestanden; in de backend een lokale OpenWork-workspace.
* [Routine](routine.md) - Een prompt die op een schema in een project draait en een nieuwe chat oplevert; draait alleen als de app open is.
