# Key

Een LiteLLM virtual key, per project of per gebruiker (zie
[Key per gebruiker of per project](../besluiten/platform/key-per-gebruiker-of-project.md)). Staat in de
OS-keychain en is nooit zichtbaar in de UI, alleen als hint ("…a1b2"). De modellenlijst komt uit LiteLLM
met de key van het project.[^contract]

[^contract]: Frontend-contract §2.
