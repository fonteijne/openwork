# Project

Eén map op schijf. Alle chats, skills, connecties en bestanden van het project horen bij die map. In de
backend is het een OpenWork-workspace (`workspaceType: "local"`). Elke chat start binnen een
project.[^contract]

Zie [Project is een workspace](../besluiten/platform/project-is-workspace.md).

[^contract]: Frontend-contract §2.
