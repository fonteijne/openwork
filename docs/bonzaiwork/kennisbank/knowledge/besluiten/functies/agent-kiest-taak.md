# De agent kiest één taak

## Context

Voor iemand die moeite heeft met kiezen en beginnen, en snel afgeleid raakt door nieuwe ideeën, helpt
een overzicht alleen niet: dat is een tweede inbox.[^agent]

## Besluit

- **De agent kiest**, jij niet: "Start hier" toont één taak; "Niet nu" geeft hooguit drie keer een
  andere (T4).
- Ideeën **parkeer** je zonder de taak te verlaten, in `inbox.md` van het persoonlijke brein; de
  avondronde deelt ze in (T5).[^agent]

## Gevolgen

- Een gevonden belofte is een voorstel met één klik, geen stille toevoeging (T6).[^agent]
