# Werkwijzen - hoe we hier werken

Elke map is een werkwijze (ICM): genummerde stappen, elk met een `CONTEXT.md` als contract. Begin bij de
`CONTEXT.md` van de werkwijze. Een nieuwe maak je met `/werkwijze`; een kopie van
`../_templates/workflow-CONTEXT.md` en `../_templates/stage-CONTEXT.md` is het begin.

Wat een run oplevert, staat in de `output/` van elke stap en wordt niet gedeeld.
