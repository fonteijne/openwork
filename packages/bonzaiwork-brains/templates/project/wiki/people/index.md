# People

Project-relevant shared person profiles live in this folder, one person per Markdown file, named `first-last.md` using the person's first and last name. Link to an individual profile when useful; do not use this index as a substitute for evidence or source attribution.

Add a profile only when it contains useful project context and the person has approved the exact shared content. Attribute self-reported information and date when it was confirmed. Keep personal or sensitive details out of shared profiles.
