# Meegeleverde skills van derden

`icm-architect/`: [RinDig/icm-architect](https://github.com/RinDig/icm-architect), MIT (zie
`icm-architect/LICENSE`), ongewijzigd overgenomen op 2026-10-30. Zonder de map `scripts/`: dat is
optionele Python die een werkruimte naar `_tools/` kopieert. In een gedeeld brein is dat code van anderen
(plan §7.1), en op een Mac zonder ontwikkeltools geeft `python3` een installatiepopup. De skill zegt zelf
dat een agent zonder shell ze kan overslaan.
